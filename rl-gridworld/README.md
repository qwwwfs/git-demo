# 强化学习实验 · SARSA 与 Q-learning

用 Python 实现表格型强化学习，让智能体在悬崖网格中从起点走到终点。两种算法共享相同的环境、奖励与训练参数，可以直接比较更新规则怎样影响走出来的路线。

## 运行

需要 Python 3.9 或以上版本，仅用标准库。

```bash
python3 train.py
python3 train.py --algorithm sarsa --episodes 3000 --epsilon 0.1 --seed 7
python3 train.py --algorithm q-learning --episodes 3000 --epsilon 0.1 --seed 7
```

Windows 也可以用 `py train.py`。

## 环境

| 元素 | 规则 |
| --- | --- |
| 状态 | 4×12 网格中的行、列坐标 |
| 动作 | 上、右、下、左，越界时留在原地 |
| 普通移动 | 每步奖励 −1，包括走到终点的那一步 |
| 踩进悬崖 | 奖励 −100，立即回到起点，本回合继续 |
| 回合结束 | 到达终点或达到 500 步上限 |

策略图中，`S` 是起点，`G` 是终点，`X` 是悬崖，箭头表示贪婪动作，`·` 表示该格所有动作的估计值仍为零。动作并列时，图上只显示其中一个。

## 两种更新规则

Q 表从全零开始。每走一步，就把当前的 `Q(s, a)` 向下表中的目标移动一小步。进入终点时，目标直接等于当步奖励。

| 算法 | 普通一步的更新目标 |
| --- | --- |
| SARSA（同策略） | `r + γ × Q(s', a')`，使用 ε-贪婪策略实际选出的下一动作 |
| Q-learning（异策略） | `r + γ × max Q(s', ·)`，使用下一状态中估值最高的动作 |

两种算法都用 ε-贪婪策略收集经验。默认 ε 为 0.1，代表每次选择动作时有 10% 的概率从四个方向中随机抽取。SARSA 的更新考虑了下一步可能继续探索，Q-learning 则按下一步选择最高估值动作来更新。

## 看实验结果

程序会打印训练前后各最多 100 回合的平均回报，以及训练后的策略图。随后固定 Q 表，分别评估纯贪婪和带探索的行动策略，各跑 100 回合，记录平均回报、到达率和掉崖次数。对照两种评估，可以看到路线长度和探索时掉崖之间的关系。

可以改动 `--epsilon` 或 `--seed` 再跑，看看路线和掉崖次数怎样变化。

## 文件

- `gridworld.py` 定义地图、移动规则和奖励。
- `train.py` 实现训练、评估和策略图输出。

这是离散导航实验。网格坐标和四方向动作可用来理解状态、动作与奖励的设计。实体机器人关节控制需要进一步建模传感器观测和连续动作。

### 默认参数的一次运行

| 算法 | 纯贪婪平均回报 | 带探索平均回报 | 带探索掉崖次数（100 回合） |
| --- | ---: | ---: | ---: |
| SARSA | −17.0 | −23.0 | 4 |
| Q-learning | −13.0 | −46.4 | 30 |

这次运行中，Q-learning 的贪婪路线沿悬崖边走，全程 13 步。SARSA 的路线绕得更远，但在保留随机探索时掉崖更少。
