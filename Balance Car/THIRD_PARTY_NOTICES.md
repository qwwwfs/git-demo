# 代码来源与许可注意事项

这个仓库以用户提供的 `Balance_car-master.zip` 工程为基础整理。整理工作主要包括文档重写、结构说明、Git 忽略规则及独立 PID 教学示例，**并不意味着整个原有固件是本次重新原创编写的**。

- 固件源代码面向 WHEELTEC B570 参考平衡车平台，具体原始代码作者和授权状态**尚未核实**。
- `Drivers/STM32F1xx_HAL_Driver/` 和 `Drivers/CMSIS/` 包含 ST 或其他第三方组件，已有的许可证说明均予以保留。
- CubeMX/HAL 生成文件中存在版权声明，不应移除。
- 本仓库没有自行添加覆盖所有文件的通用开源许可证，因为并未确认每个部分的著作权来源及授权范围。

**公开发布前**请核对你有权再分发的代码范围。如果原代码来自他人的 GitHub 仓库，应按原许可证要求保留版权和来源，必要时改为 Fork 并注明自己修改的部分。如果不确定授权，可仅发布自己的学习笔记、实验代码和图片，并链接到原项目。
