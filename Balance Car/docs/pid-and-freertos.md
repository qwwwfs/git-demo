# PID 和 FreeRTOS：当前工程与简历的差异

## 当前压缩包实际实现

- 平衡主算法：`Core/CODE/car_lqr_control.cpp`，LQR 控制；不是 PID。
- 运行方式：STM32 HAL + MPU6050 外部中断控制闭环 + TIM2 自定义辅助调度；**没有集成 FreeRTOS**。
- 额外提供了 `examples/pid_basics/`：独立 PID C++ 练习，用于理解算法和测试，不会被原固件编译进去。

## 如果你确实做过 FreeRTOS + PID 实物小车

请把实际使用的那一版程序（包括 `FreeRTOSConfig.h`、任务创建以及 PID 控制函数）单独整理上传，最好附上运行截图或固件版本说明。**不能用当前 LQR 固件替代证明。**

## 若以后想把本工程改为 FreeRTOS + PID

1. 先为 STM32F103 配置匹配内存的 FreeRTOS 内核，检查 HAL Tick 与 RTOS 中断优先级和栈/堆设置。
2. 先在电脑端使用 `examples/pid_basics/` 学习 PID，再设计角度环/速度环等车端控制器。
3. 保证传感器控制的实时性：避免在高优先级中断中做长时间 I2C/串口/阻塞调用；考虑外部中断发通知、控制任务完成采样与电机计算。
4. 根据真实电机和姿态方向重新整定参数，保留倾倒停机与 PWM 限幅。
5. 先架空测试，再进行有安全约束的落地测试，记录版本、误差曲线与结果。

这是**后续迁移建议**，不是本次已经完成的功能。
