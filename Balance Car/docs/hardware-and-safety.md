# 硬件信息和调试安全

> 以下硬件基于上传的参考工程和 `BalancingCar.ioc`；不同批次板子或改线后需要重新核对。

| 模块 | 工程中的配置 |
| --- | --- |
| MCU | STM32F103C8Tx |
| MPU6050 | PB8 / PB9 软件 I2C；PA12 外部中断 |
| 编码器 | TIM3、TIM4 |
| 电机输出 | TIM1 CH1/CH4 PWM；GPIO 电机方向 |
| 上位机串口 | USART1 |
| 蓝牙 | USART3 |
| 显示 | OLED（具体接线以源码、板卡为准） |
| 电池检测 | ADC1，当前代码默认关闭监测和保护 |

## 上电前检查

1. 核对板卡型号、供电极性、电池规格和接线，确认与 `.ioc` 及 `Core/Inc/main.h` 一致。
2. 检查电机方向与编码器方向；首先**架空车轮**，并限制输出功率。
3. 检查 MPU6050 的原始读数、倾角方向和直立零点。
4. 查看控制器的 PWM 限幅，确保可快速断电；不要在人员或易碎物附近进行初次落地测试。
5. 确认紧急停机功能可靠后，逐步增加实验负载和控制增益。

**注意：** 当前代码内的低电量监测与保护宏默认处于关闭状态。不要将这些代码视为已具备完整电池保护功能的证明。
