# 真实硬件接入清单

当前没有真实 CAN 实现。不能通过切换参数直接控制实物。

需要补充：
1. RDK 型号、系统镜像、ROS2 发行版与 CAN 适配器型号。
2. 电机与驱动器型号、厂商协议、波特率、节点 ID、帧格式。
3. 电机角与关节角换算：减速比、零点、方向及角度单位。
4. 关节机械限位、额定电流、速度限制及供电配置。
5. 位置/速度/故障反馈解码和使能、停机、故障复位报文。

接入步骤：按厂商协议实现 CANDriver，先测试编解码，再完成反馈接收和超时停机。
将 ArmNode 的模拟驱动替换为经过验证的驱动，发布实际编码器反馈。
真实控制需增加独立使能流程、通信看门狗和可用的急停；模拟器的位置保持语义不能直接当作硬件停机策略。
先单电机低速验证方向与零点，再连机构验证双关节动作。

后续 README 建议增加实物照片、接线图、协议出处和实际测试记录；没有完成的测试保持“待验证”。
